# mail-postage-web

中国邮政资费查询网页。资费数据与前端位于同一个仓库，页面运行时直接读取 `postage/` 下的结构化 JSON。

当前数据规范版本：`1.5.0`。

## 页面结构

- 国内
  - 函件
  - 包裹（邮政普通包裹 / 家乡包裹贴）
- 国际
  - 国际：邮件种类与运输方式分开选择
  - 港澳台

## 国际目的地搜索

国际目的地使用文字联想输入。停止输入约 1 秒后显示匹配项。

- `英` → 可匹配英国
- `GB` → 英国
- `UK` → 作为 GB 的常用输入别名匹配英国

## 特别业务 UI

`selection.mode=display-only` 的项目：

- **不会生成复选框**
- 不参与计算
- 统一放在特别业务列表下方的“仅公示”区域

包括国内存局候领、撤回/改址，以及国际/港澳台的国际回信券、撤回/改址、进口欠资、存局候领、逾期保管、海关查验等。

### 复选框联动

网页在复选框 `change` 时立即执行依赖，而不是等点击“查询资费”。

国际/港澳台：

1. 勾选回执 → 自动勾选挂号。
2. 勾选保价费 → 自动勾选保价函件手续费。
3. 保价函件手续费已含挂号，因此勾选后自动取消并禁用独立挂号费。
4. 已有“回执 + 挂号”时再勾选保价：回执保留，挂号自动取消，保价手续费自动勾选。
5. 取消保价函件手续费：保价费自动取消；如果回执没有其他挂号前提，回执也取消。
6. 取消挂号：所有仅依赖挂号的回执/保价自动取消。

国内函件：

- 回执要求挂号。
- 保价只允许信函，要求挂号，最高保价金额 20000 元。
- 取消挂号会级联取消依赖它的回执/保价。
- 约投只对信函有效，且不能与保价同时使用。

## 国内包裹

### 邮政普通包裹

- 基础资费已包含挂号属性，附回执不另收挂号费。
- 可同时办理保价和回执。
- 保价费 = 保价金额 × 1%，最高保价金额 100000 元。
- 普通包裹不提供存局候领手续费业务。
- 8折/7折优惠只作用于基础寄递资费；保价费、回执费不打折。
- 可填写长宽高；泡重 = `长 × 宽 × 高 ÷ 6000`（kg）。
- 尺寸完整时分别显示实重资费和泡重资费，并采用较高基础资费。

### 家乡包裹贴

- 可保价：保价金额 1%，最高 100000 元。
- 不可回执。
- 不使用普通包裹折扣和泡重规则。
