# mail-postage-web

中国邮政资费查询网页。资费数据与前端位于同一个仓库，页面运行时直接读取 `postage/` 下的结构化 JSON。

## 查询结构

- **国内**
  - **函件**：信函、明信片、印刷品、邮简、义务兵免费信函、盲人读物
  - **包裹**：邮政普通包裹、家乡包裹贴
- **国际**
  - **国际**：邮件种类与运输方式分开选择，运输方式包括数据中实际可用的 AIR / SAL / SURFACE
  - **港澳台**：香港、澳门、台湾基本寄递资费

## 目的地搜索

国际目的地使用文字联想输入。输入停止约 1 秒后显示匹配项，可按中文名称、ISO 代码和部分常用别名匹配。例如：

- 输入 `英` → 可匹配英国
- 输入 `GB` → 英国
- 输入 `UK` → 英国（作为 GB 的常用输入别名处理）

选择联想结果后再进行资费计算。

## 国内普通包裹

- 按起寄省、寄达省和总重量档计算
- 可选填写长、宽、高（cm）
- 泡重公式：`长 × 宽 × 高 ÷ 6000`，结果单位 kg
- 尺寸完整时，页面分别计算并展示**实重资费**和**泡重资费**，高亮较高项，并以较高的基础寄递资费作为计费基础
- 普通包裹基础资费已包含挂号属性，因此附回执时不另收挂号费
- 普通包裹可办理保价，也可办理回执，两者不冲突
- 当前数据未提供国内普通包裹保价费率，因此网页只公示“可保价”，不会套用函件保价费率
- 8折/7折优惠只作用于普通包裹**基础寄递资费**；回执费、保价费等特别业务费按原价另加
- 优惠一次只能使用一个，不允许叠加

## 家乡包裹贴

- `≤1kg / ≤3kg / ≤5kg / ≤10kg` 阶梯资费
- 可办理保价，但当前保价费率未录入，因此只公示能力
- 不可办理回执
- 不使用普通包裹优惠，也不使用普通包裹体积重规则

## 特别业务

页面按照 `postage/spec/special-services.json` 处理特别业务：

- `selectable`：可在寄件时选择并参与计算
- `display-only`：只公示，不加入寄件总价
- 回执/保价等依赖业务会自动补足所需项目
- 已包含的费用不会重复计收
- 互斥项目会拒绝同时计算

存局候领、撤回/改址、进口欠资、逾期保管、海关验关等非交寄时费用只展示。国际/港澳台保价函件保价费会自动要求保价函件手续费；该手续费已经包含挂号费，因此不会重复计收挂号费。台湾回执限制仍按 notice 执行。

## 数据入口

```text
postage/index.json
postage/services.json
postage/domestic/provinces.json
postage/rates/
postage/zones/
postage/special-rates/
postage/spec/
```

当前数据规范版本为 `1.4.0`。

## GitHub Pages

仓库包含：

```text
.github/workflows/pages.yml
.nojekyll
```

在 **Settings → Pages** 中把 Source 设置为 **GitHub Actions**。之后推送到 `main` 会自动发布。

> 本项目及数据不是中国邮政官方发布渠道，仅供查询参考；实际收费、可寄达性和收寄条件以中国邮政营业网点及最新规定为准。
